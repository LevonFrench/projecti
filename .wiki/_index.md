This directory serves as the knowledge base for our card game project, following the standard LLM-Wiki structure.

## Structure
- [[wiki/_index|Living Wiki Documentation (wiki/)]] ([wiki/](wiki/_index.md)) - Holds compiled articles, concepts, topics, and theses.
- [[raw/_index|Raw Material Sources (raw/)]] ([raw/](raw/_index.md)) - Immutable original research sources.
- [[inbox/_index|Inbox Directory (inbox/)]] ([inbox/](inbox/_index.md)) - Incoming research files waiting for ingestion.
- [[output/_index|Reports Output (output/)]] ([output/](output/_index.md)) - Generated playbooks, roadmaps, and reports.
- [[inventory/_index|Tracking Inventory (inventory/)]] ([inventory/](inventory/_index.md)) - Project registries and watch items.
- [[datasets/_index|Manifest Datasets (datasets/)]] ([datasets/](datasets/_index.md)) - File lists for external datasets.
